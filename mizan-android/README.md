# ميزان — متتبّع المصروفات

تطبيق Android أصلي بلغة Kotlin وواجهة عربية. لا يحتاج إلى حساب أو اتصال بالإنترنت؛ تُحفظ الحركات محليًا على الجهاز.

## ما يتضمنه

- تسجيل الدخل والمصروف مع تصنيف وملاحظة.
- ملخص شهري للدخل والمصروف وصافي الرصيد.
- التنقل بين الأشهر، وتعديل الحركات أو حذفها.
- اختيار العملة بين الريال اليمني، الريال السعودي، الدولار، والدرهم الإماراتي.
- دعم الأرقام العربية والإنجليزية عند إدخال المبالغ.

## فتح المشروع

افتح مجلد `mizan-android` في Android Studio، ثم وافق على مزامنة Gradle. يتطلب البناء Android SDK 35 وJDK 17. لإنشاء ملف APK اختر:

**Build → Build Bundle(s) / APK(s) → Build APK(s)**

لا يطلب التطبيق صلاحية الإنترنت. البيانات محفوظة في مساحة التطبيق الخاصة على الهاتف، لذلك حذف التطبيق يمسح هذه البيانات.

## بناء APK تلقائيًا من GitHub

يوجد سير عمل GitHub Actions في `.github/workflows/build-android-apk.yml`. بعد رفع المشروع إلى GitHub، يبدأ البناء تلقائيًا عند تغيير ملفات التطبيق، أو يمكنك تشغيله من تبويب **Actions** باختيار **Build Android APK** ثم **Run workflow**. بعد نجاح البناء، نزّل الملف `mizan-debug-apk` من صفحة التشغيل. هذا APK تجريبي موقّع للتثبيت والاختبار، وليس إصدارًا مهيأً للنشر على Google Play.
